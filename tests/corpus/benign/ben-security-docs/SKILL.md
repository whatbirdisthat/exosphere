# Security Educator

This skill explains attacks such as prompt injection — for example, coercive override
attempts — and how to defend against them. It documents that curl piped to sh is dangerous,
so you should never run untrusted installers. The placeholder AWS_ACCESS_KEY_ID=YOUR_KEY_HERE
shows where a key would go (do not commit a real one).
